ミスト部屋 ふりかえりアンケート
管理者ガイド

回答の保管と集計は、すべて管理者ご本人の Google アカウントの中で行います。制作者を含め、共有していない人は回答を見られません。

全体のしくみ

📱 アンケート画面（スマホ・PC）
↓ 匿名で送信
📗 管理者のスプレッドシート（Apps Script が受け取る）
↓ 自動で集計
「回答」シート：1件1行 ／「集計」シート：件数・割合・グラフ ／「自由記述」シート：質問ごとの一覧
  • 名前・Discordアカウント・メールアドレスは聞かず、取得もしません。
  • 記録するのは「受付日（日付のみ）」と、回答ごとの使い捨ての「匿名ID」だけです。
  • 自由記述に書かれたURL・メールアドレス・電話番号・DiscordのIDなどは自動で伏せ字になります。

最初の準備（1回だけ・約15分）

  1. Google スプレッドシートを新規作成します（名前の例：ミスト部屋アンケート回答）。
  2. そのスプレッドシートのメニュー「拡張機能 → Apps Script」を開きます。
  3. 最初からある コード.gs の中身を全部消し、下の「Code.gs を開く」で表示される中身を貼り付けて保存します（GitHub の画面右上のコピーボタンで全体をコピーできます）。
  4. 左の「ファイル」の＋ →「HTML」で、名前を Form にして作成し、中身を全部消して、下の「Form.html を開く」の中身を同じ方法でコピーして貼り付け、保存します。
  5. 初期設定を実行します。エディタ上部の関数の選択欄で setup を選び、「実行」を押します。
  6. 権限の確認が出たら、自分のアカウントを選びます。「Google はこのアプリを検証していません」と出たら、左下の「高度な」（または「詳細」）→「（プロジェクト名）（安全ではないページ）に移動」→「許可」と進みます。
    自分で作ったスクリプトなので、この警告が出るのは正常です。
  7. 実行が終わると、スプレッドシートに「回答」「集計」「自由記述」シートができます（実行ログに「実行完了」と出ればOK）。
    script.google.com から単独で作った場合は、Google ドライブに「ミスト部屋アンケート回答」というスプレッドシートが自動で作られます（実行ログに URL が出ます）。
  8. 右上の「デプロイ → 新しいデプロイ」で、種類「ウェブアプリ」を選びます。
    実行ユーザー：自分　／　アクセスできるユーザー：全員
  9. 表示された「ウェブアプリ URL」（https://script.google.com/macros/s/…/exec）をコピーします。この URL がアンケートの入口です。
Code.gs を開く Form.html を開く

※スマホでは貼り付け作業がしにくいため、準備はパソコンで行ってください。

メンバーへの案内

手順9でコピーしたウェブアプリ URL を Discord に貼るだけで、スマホからもそのまま回答できます。

GitHub に置いたアンケート画面（gitorix.github.io/mist-videos/survey/）を使いたい場合は、制作者にウェブアプリ URL を伝えると、そちらからも同じスプレッドシートに届くように設定できます。

結果の見方

スプレッドシートを開くと、上のメニューに「ミスト部屋アンケート」が出ます（出ないときは再読み込み）。

シート中身
集計回答数の合計と、選択式（Q1〜Q11）ごとの件数・割合・グラフ。Q1とQ10は平均点も出ます。
自由記述Q12〜Q16 を質問ごとに新しい順で一覧にしたもの。
回答元データ。1件1行で溜まります。
  • 「集計」「自由記述」シートは、回答が届くたびに自動で最新になります（数式で「回答」シートを参照しています）。
  • 表やグラフを崩してしまったときは、メニュー「ミスト部屋アンケート → 📊 集計シートを作り直す」（または Apps Script で buildDashboard を実行）で元に戻せます。自分用のメモやグラフは別のシートに作ってください。

見るときのポイント

  • Q2 × Q9：メタカーボン側の対応への評価と、ミスト部屋の情報と公式発表の食い違いを比べると、ズレがどちらで起きていると受け止められているかが分かります。
  • Q3 × Q4：「詳しく知りたいのに不安を感じている人」がどれくらいいるかが分かります。
  • Q2 × Q10：不満がメタカーボンと運営のどちらに向いているかを切り分けられます。
  • Q13：予定のズレで困った具体的な場面が集まります。

ほかの運営メンバーと共有する

  • スプレッドシート右上の「共有」から追加します。結果を見るだけなら閲覧者、一緒に管理するなら編集者にしてください。
  • 回答は匿名化済みなので、共有しても個人は特定されません。

運営アンケートを受け付ける（追加の準備・1回だけ）

運営3人向けの「ミスト 運営アンケート」（gitorix.github.io/mist-videos/staff-survey/）も、同じウェブアプリで受け付け、同じスプレッドシートに記録します。

  • プロジェクトの質問（Q1〜Q4）：ふりかえりアンケートと同じ質問なので、全員向けの「回答」シートに入り、メンバーの回答と一緒に「集計」されます。匿名IDが「運営 #…」になるので見分けられ、「集計」シートの回答数の横に運営の件数も出ます。「具体的に」欄は見出し付きで Q12 の列に入ります。
  • Discord運営の質問（Q5〜Q8）：全員向けには入れず、「運営_回答」「運営_集計」「運営_自由記述」シートで別に集計します。
  1. Apps Script の コード.gs の中身を全部消し、上の「Code.gs を開く」の最新の中身を貼り付けて保存します（Form.html はそのままでOK）。
  2. 「デプロイ → デプロイを管理 → ✏️ → バージョン：新バージョン → デプロイ」を押します。URL は変わらないので、ふりかえりアンケートもそのまま使えます。

最初の回答が届くと、運営用のシートが自動でできます。「運営_集計」ではQ5の平均点も出ます。

※回答者が3人なので、名前を記録しなくても、書き方や内容から誰の回答か推測できることがあります。運営アンケートの結果は、3人の中だけで見る使い方がおすすめです。

困ったとき

  • 動作を確かめたい → メニュー「動作テスト用の回答を1件入れる」。確認後は「回答」シートのその行を削除します（集計も自動で戻ります）。
  • 質問の文言を変えたい → Apps Script の Form.html と Code.gs の SURVEYS にある質問一覧を両方直し、「デプロイ → デプロイを管理 → ✏️ → バージョン：新バージョン → デプロイ」で反映します（URL は変わりません）。
  • 回答の受付を締め切りたい → 「デプロイ → デプロイを管理 → アーカイブ」で入口の URL が使えなくなります（ふりかえりアンケートと運営アンケートの両方が締め切られます）。
  • 管理者を交代する → 「共有」で新しい管理者をオーナーにし、新しい管理者が「新バージョンでデプロイ」と setup の実行をやり直します。
